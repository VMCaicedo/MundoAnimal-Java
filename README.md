## Preguntas de reflexión

**23. ¿Qué se reutiliza al heredar de Animal?**

Se reutilizan sus atributos y métodos, como el nombre, la edad y el método para mostrar información.

**24. ¿Qué hace super(nombre, edad)?**

Llama al constructor de la clase padre (`Animal`) para asignar el nombre y la edad del animal.

**25. ¿Para qué sirve @Override?**

Sirve para indicar que estamos modificando un método que viene de la clase padre o de una interfaz.

**26. ¿Por qué el mismo método hacerSonido() produce resultados distintos?**

Porque cada animal tiene su propia forma de hacer sonidos. Por ejemplo, el perro ladra y el gato maúlla. Esto es parte del polimorfismo.

**27. ¿Cuál es la diferencia entre una clase abstracta y una interfaz?**

Una clase abstracta puede tener atributos, constructores y métodos. Una interfaz sirve para establecer métodos que las clases deben implementar.
